# Conflicts between sources
Updated: YYYY-MM-DD. Copy this file to `_system/CONFLICTS.md`.

## Rules
1. **Do not choose silently.** When you find two sources that disagree (two notes, or a note and a document), answer with both, say that they conflict, and add a row below.
2. **Short paraphrase, not a copy.** Write what each source says in a few words. Do not paste long passages and **never paste a secret or personal data**.
3. **Mark the notes involved:** set `claim_status: mixed` in their frontmatter (frontmatter only; never change a body for this).
4. **Someone decides** (name the role, not a guess). Until then the conflict stays open and answers must show both versions.
5. When it is decided, move the row to **Closed** with the date and the decision, fix the wrong note in the normal way, and update `claim_status` if nothing is left to doubt.
