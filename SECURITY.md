# Security policy

Please report vulnerabilities privately: open the **Security** tab of this repository and choose **Report a vulnerability**. Do not open a public issue for a security problem, and do not include real secrets or private data in a report.

What is in scope: anything that makes the tools write, delete or send data they should not, print a secret value, or follow instructions found inside notes.

We aim to acknowledge reports within a few days. This is a small project maintained in spare time; there is no bug bounty.
